# Product

## Register

product

## Platform

web

## Users

Invited Hazelwood Minecraft players use the site to register with a nickname and password, then view their profile, server presence, and map. Server admins create one-use invitations and ban players. Visitors can see the current server status and map.

## Product Purpose

Provide Hazelwood players with a small web profile connected to the Minecraft server. Success means an invited player can create one account, see whether players are online and who they are, and open a cached, angled world map.

## Positioning

An invite-only player portal for Hazelwood, with live server status and an angled map of the world.

## Brand Personality

Minecraft-led and exploratory, with restrained woodland and wood details drawn from the Hazelwood name. Visual references are official Minecraft promotional videos, screenshots, and websites.

## Anti-references

None specified.

## Design Principles

- One invitation code creates one account.
- Registration asks only for a Minecraft nickname and password, plus the invitation code required to enter.
- Keep the web app and its background work small; cache the server map and status.
- Let Minecraft imagery lead, with Hazelwood details as accents.

## Accessibility & Inclusion

Support narrow screens, readable contrast, keyboard navigation, and reduced motion. No additional requirements were specified.
