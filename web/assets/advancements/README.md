# Advancement icons

These 126 icons are Minecraft Java Edition 26.3 vanilla item textures, mapped from each advancement’s `display.icon` item. Files follow the advancement ID path under `minecraft/` so the profile UI can resolve IDs directly. A few special inventory models have no standalone item sprite in the vanilla client assets; their representative source textures are recorded in `manifest.json`.

Source archive: the locally installed Minecraft Java Edition 26.3 client JAR. The item assignments come from the matching 26.3 server advancement JSON files.
